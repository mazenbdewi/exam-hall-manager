# نظام إدارة الامتحانات وتوزيع القاعات

يوفر النظام لوحة لإدارة العمل الامتحاني في الجامعة، وتشمل تجهيز البيانات الأساسية، قوائم طلاب المواد، توليد البرنامج الامتحاني، تثبيت البرامج المعتمدة، توزيع الطلاب على القاعات، توزيع المراقبين، ثم التقارير والطباعة والاستعلامات.

## دليل الاستخدام

تم تحديث دليل الاستخدام العربي ليشرح سير العمل الجديد خطوة بخطوة للمستخدمين الإداريين. يمكن تحميل النسخة الأحدث من داخل التطبيق عبر:

`المساعدة` ثم `تحميل دليل الاستخدام`

كما توجد نسخة نصية في [docs/user-guide.md](docs/user-guide.md).

## ملاحظات للمطورين

أبرز الميزات الحديثة التي يجب مراعاتها عند التطوير:

- البرامج الامتحانية المثبتة تحفظ Snapshot مستقلًا عن المسودة الحالية، وتستخدم كنسخ رسمية للطباعة لاحقًا.
- صفحة التوزيع الشامل تعرض حالة التوزيع وآخر نتيجة محفوظة وأعداد الطلاب الموزعين وغير الموزعين.
- قسم `التقارير والطباعة` يجمع روابط وتقارير الطباعة بدل توزيعها داخل صفحات التشغيل.
- طباعة تفقد القاعات تعتمد على توزيع الطلاب، وتكتمل بيانات رئيس القاعة وأمين السر والمراقبين بعد توزيع المراقبين.
- يوجد اعتماد واضح بين تفقد القاعات وتوزيع المراقبين لمنع الطباعة النهائية الناقصة.
- تمت إضافة تقرير توزيع أعداد الطلاب على القاعات حسب الفترة الامتحانية.
- تمت إضافة كشف توزيع الطلاب على القاعات حسب المادة والفترة، مع فرز أبجدي وتوليد أرقام جلوس وقت الطباعة.
- توجد مسارات طباعة مخصصة داخل لوحة Filament مثل مسارات برنامج الامتحان، تفقد القاعات، وتقارير التوزيع.
- صفحات الطباعة تستخدم Blade وCSS مخصصين لدعم العربية وRTL، وبعض التقارير تستخدم mPDF لإخراج PDF مباشر.

## النسخ الاحتياطي

تم إعداد نسخ احتياطي محمي لقاعدة البيانات فقط داخل لوحة Filament. راجع [docs/backup.md](docs/backup.md) لمعرفة طريقة الإنشاء، التحميل، الجدولة، والاستعادة.
